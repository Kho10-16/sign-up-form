# Sign-up Form

A sign-up page for an imaginary service, built as part of [The Odin Project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-sign-up-form) Intermediate HTML and CSS course.

**Live preview:** https://YOUR-USERNAME.github.io/sign-up-form/

## Features

- Two-panel layout built with Flexbox: an image sidebar and a form area
- Semi-transparent logo band so the text stays readable over the background photo
- Custom font loaded with `@font-face`
- Built-in HTML validation (`required`, `type="email"`, `minlength`, `pattern`)
- Input states styled with CSS pseudo-classes:
  - `:focus`: blue border and soft shadow on the selected input
  - `:user-invalid`: red border on invalid input, shown only after the user interacts

## What I learned

- Structuring a form with `<label for>` and matching `id`s for accessibility
- Connecting a button outside a `<form>` using the `form` attribute
- The difference between `:invalid` and `:user-invalid`
- Building a two-column layout with `flex-wrap` and `calc()`

## Built with
